# v0.1 API Contracts

> Concrete wire shapes for the v0.1 vertical slice. Lives next to
> [`V0.1_STORIES.md`](V0.1_STORIES.md) so the user stories and the bytes
> they move can be reviewed together.

**Conventions**

- All requests and responses are JSON (`application/json`).
- All timestamps are ISO-8601 with offset (`2026-09-26T12:34:56.789Z`).
- All ids are UUID v4 strings.
- All errors share one envelope (see §0).
- Authentication is a short-lived JWT in `Authorization: Bearer <token>` plus
  a refresh-token cookie. Anonymous requests to authenticated endpoints
  return `401`.

---

## 0. Error envelope

Every error response uses the same shape:

```json
{
  "code":    "string_machine_readable",
  "message": "Human-readable description, safe to show to the user."
}
```

| HTTP | When |
|------|------|
| `400` | Validation failed. `code` is one of: `first_name_and_last_name_required`, `weak_password`, `validation_failed`. |
| `401` | Missing or invalid credentials. `code = invalid_credentials` or `token_expired`. |
| `403` | Authenticated but not authorized for the requested workspace. `code = forbidden`. |
| `404` | Resource not found (or soft-deleted). Body is omitted. |
| `409` | Conflict — version mismatch or duplicate. `code = stale_version` or `duplicate` or `setup_already_complete`. |
| `429` | Rate-limited. `code = too_many_requests`. `Retry-After` header set. |
| `500` | Unexpected server error. Body is `{ "code": "internal", "message": "An unexpected error occurred." }`. The full exception is logged with a `traceId`. |

## 1. Setup wizard

### `POST /api/setup` — first-run only

Creates the first instance admin and their personal workspace. Refuses
after the first successful call.

**Request**

```json
{
  "email":       "ada@example.com",
  "password":    "correct-horse-battery-staple",
  "displayName": "Ada Lovelace",
  "siteName":    "Lovelace CRM"
}
```

**Response — `200 OK`**

```json
{
  "userId":      "5fa85f64-5717-4562-b3fc-2c963f66afa6",
  "workspaceId": "7c9e6679-7425-40de-944b-e07fc1f90ae7"
}
```

Sets cookies: `pcrm_refresh` (httpOnly, Secure, SameSite=Lax, 30 days).

**Errors**

| Code | HTTP | When |
|------|------|------|
| `setup_already_complete` | 409 | An admin already exists. |
| `weak_password` | 400 | Password shorter than 12 chars, or matches the email local-part. |
| `validation_failed` | 400 | Missing or malformed fields. |

## 2. Authentication

### `POST /api/auth/login`

```json
{
  "email":    "ada@example.com",
  "password": "correct-horse-battery-staple"
}
```

**Response — `200 OK`**

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "expiresAt":   "2026-09-26T12:49:56Z"
}
```

Sets cookies: `pcrm_refresh` (httpOnly, Secure, SameSite=Lax, 30 days).

**Errors**

| Code | HTTP | When |
|------|------|------|
| `invalid_credentials` | 401 | Email not found or password wrong. Same body for both (no enumeration). |
| `too_many_requests`   | 429 | More than 10 attempts in the last minute. |

### `POST /api/auth/refresh`

Reads the refresh cookie, rotates it, returns a new access token.

**Response — `200 OK`**

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "expiresAt":   "2026-09-26T12:49:56Z"
}
```

**Errors**

| Code | HTTP | When |
|------|------|------|
| `invalid_credentials` | 401 | Refresh token missing, malformed, expired, or already rotated. |

### `POST /api/auth/logout`

Revokes the current refresh token and clears the cookie.

**Response — `204 No Content`.**

## 4. Contacts

> The `workspaces/{id}` segment is the active workspace. The server
> enforces membership on every call; non-members get `403`.

### `GET /api/workspaces/{id}/contacts?limit=50&offset=0&q=ada&includeDeleted=false`

**Response — `200 OK`**

```json
{
  "contacts": [
    {
      "id":          "1b9d6bcd-bbfd-4b2d-9b5d-ab8dfbbd4bed",
      "workspaceId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
      "firstName":   "Ada",
      "middleName":  null,
      "lastName":    "Lovelace",
      "fullName":    "Ada Lovelace",
      "pronouns":    "she/her",
      "photoUrl":    null,
      "birthday":    "1815-12-10",
      "anniversary": null,
      "cadenceDays": 30,
      "circles":     [],
      "tags":        [],
      "createdAt":   "2026-09-26T12:34:56.789Z",
      "updatedAt":   "2026-09-26T12:34:56.789Z",
      "lastContactedAt": "2026-09-25T09:00:00Z"
    }
  ],
  "nextOffset": null
}
```

**Errors** — `403 forbidden`, `401 invalid_credentials`.

### `GET /api/workspaces/{id}/contacts/{contactId}`

**Response — `200 OK`** with the full `ContactDto` (same shape as in the list above).

**Errors** — `404`, `403`, `401`.

### `POST /api/workspaces/{id}/contacts`

**Request**

```json
{
  "firstName":   "Ada",
  "middleName":  null,
  "lastName":    "Lovelace",
  "pronouns":    "she/her",
  "birthday":    "1815-12-10",
  "anniversary": null,
  "cadenceDays": 30
}
```

**Response — `201 Created`**

Headers: `Location: /api/workspaces/{id}/contacts/{contactId}`.

Body: the full `ContactDto` of the newly created contact.

**Errors**

| Code | HTTP | When |
|------|------|------|
| `first_name_and_last_name_required` | 400 | One of the names is missing or whitespace. |
| `validation_failed` | 400 | Other field invalid (e.g. negative `cadenceDays`). |

### `PATCH /api/workspaces/{id}/contacts/{contactId}`

Optimistic-concurrency update.

**Request**

```json
{
  "id":              "1b9d6bcd-bbfd-4b2d-9b5d-ab8dfbbd4bed",
  "expectedVersion": 0,
  "firstName":       "Augusta Ada",
  "middleName":      null,
  "lastName":        "Lovelace",
  "pronouns":        "she/her",
  "birthday":        "1815-12-10",
  "anniversary":     null,
  "cadenceDays":     30
}
```

**Response — `200 OK`** with the updated `ContactDto` (new `version`).

**Errors**

| Code | HTTP | When |
|------|------|------|
| `stale_version` | 409 | `expectedVersion` does not match the row's current version. |
| `validation_failed` | 400 | Names missing or fields invalid. |
| `404` | 404 | Not found. |

### `DELETE /api/workspaces/{id}/contacts/{contactId}`

Soft-deletes the contact (sets `DeletedAt`).

**Response — `204 No Content`.**

## 5. Interactions

### `POST /api/workspaces/{id}/interactions`

```json
{
  "clientGeneratedId": "018f3e7c-3b8e-7e3a-b0b3-2d5b9e0a1c2d",
  "kind":              "Call",
  "direction":         "Outbound",
  "occurredAt":        "2026-09-25T09:00:00Z",
  "durationMinutes":   18,
  "location":          "Athens",
  "summary":           "Discussed the new release plan.",
  "participantContactIds": ["1b9d6bcd-bbfd-4b2d-9b5d-ab8dfbbd4bed"]
}
```

**Response — `201 Created`** with `InteractionDto`. `Location` header set.

**Idempotency.** The server uses `clientGeneratedId` (UUIDv7) as the
idempotency key. Re-posting the same key returns the original interaction
instead of creating a duplicate. This is the mechanism that makes offline
write replay safe.

**Errors** — `404` (one of the `participantContactIds` doesn't exist in the workspace), `403`, `400`.

### `GET /api/workspaces/{id}/contacts/{contactId}/interactions?limit=100&before={isoDate}`

Timeline of interactions for a single contact, newest first.

**Response — `200 OK`**

```json
{
  "interactions": [
    {
      "id":                 "a2c1f5e8-9e3a-4a4f-9c8a-9b9f0c5a1e2d",
      "workspaceId":        "7c9e6679-7425-40de-944b-e07fc1f90ae7",
      "clientGeneratedId":  "018f3e7c-3b8e-7e3a-b0b3-2d5b9e0a1c2d",
      "kind":               "Call",
      "direction":          "Outbound",
      "occurredAt":         "2026-09-25T09:00:00Z",
      "durationMinutes":    18,
      "location":           "Athens",
      "summary":            "Discussed the new release plan.",
      "version":            0,
      "participantContactIds": ["1b9d6bcd-bbfd-4b2d-9b5d-ab8dfbbd4bed"],
      "createdAt":          "2026-09-25T09:00:01Z",
      "updatedAt":          "2026-09-25T09:00:01Z"
    }
  ],
  "nextCursor": null
}
```

## 6. Reminders

### `POST /api/workspaces/{id}/reminders`

```json
{
  "title":   "Call Mom",
  "dueAt":   "2026-09-30T18:00:00Z",
  "notes":   "Wish her a happy birthday next week.",
  "contactId": null
}
```

`kind` is inferred: `OneOff` if no `contactId`, `CustomDate` if linked to a contact without a birthday, otherwise `Birthday`/`Anniversary` (those kinds are auto-created).

**Response — `201 Created`** with `ReminderDto`.

### `GET /api/workspaces/{id}/reminders?upcoming=true&overdue=true&kind=Birthday&limit=50`

**Response — `200 OK`** with `{ "reminders": [...], "nextCursor": null }`.

### `PATCH /api/workspaces/{id}/reminders/{reminderId}`

```json
{
  "expectedVersion": 0,
  "status":          "Completed",
  "snoozedUntil":    null
}
```

`status` is one of `Pending | Completed | Dismissed`.

## 7. Health

### `GET /healthz` — always `200 OK` (liveness).

### `GET /readyz` — `200 OK` when DB + storage + (optional) SMTP respond. `503 Service Unavailable` otherwise.

Body: `{ "checks": { "db": "ok", "storage": "ok", "smtp": "skipped" } }`.

---

## 8. Pagination

Two strategies depending on the endpoint:

- **Offset** for low-cardinality lists (`/contacts`): `?limit=50&offset=0`. `nextOffset` is `null` when there are no more.
- **Cursor** for time-series lists (`/interactions`, `/reminders`): `?before={isoDate}&limit=100`. `nextCursor` is the `occurredAt` of the last item, or `null` when there are no more.

Hard cap on `limit`: 200 for contacts, 100 for interactions/reminders. Larger values are clamped.

---

## 9. Headers every response carries

| Header | When |
|--------|------|
| `TraceId` | Always. Mirrors `traceparent` for distributed tracing. |
| `Cache-Control: no-store` | Always, on authenticated responses. |
| `Retry-After` | Only on `429`. |
| `Location` | On `201` and the rare `202` we use (none in v0.1). |

---

## 10. Versioning

API URLs are versioned by path prefix from v1.0 onwards. v0.1 ships
unversioned (`/api/...`) and becomes the baseline of `/api/v1/...` at GA.
Breaking changes will require a new major version prefix.
